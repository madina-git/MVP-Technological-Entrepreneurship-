Dependency analysis

New dependency scan

Check package versions against known public vulnerability advisories. Your source code is not required. Upload only a dependency manifest or lockfile.

Supported inputs: package.json, package-lock.json, requirements.txt, pom.xml, or a name/version list. Vulnerability checks need exact package versions; ranges are not treated as exact versions.
Privacy by design. This browser-only prototype reads the dependency list locally and sends package names and versions to OSV.dev to look up public vulnerability records when the API is reachable. It does not upload source code. Do not paste secrets or private source files.

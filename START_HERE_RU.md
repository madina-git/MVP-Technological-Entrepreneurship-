# DepSentry — как открыть проект на защите

## Быстрый запуск
1. Распакуйте архив целиком в отдельную папку, например `Desktop\\depsentry-mvp`.
2. Откройте папку. Главный файл сайта — `index.html`.
3. Дважды нажмите `index.html`: он откроется в Chrome, Edge или Firefox.
4. В меню слева выберите **New scan**. Для демонстрации можно нажать **Load example**, затем **Check dependencies**.
5. Для реальной проверки нужен интернет: сайт отправляет названия пакетов и точные версии в публичный API OSV.dev. Если API недоступен, покажется ошибка подключения.

Ничего устанавливать не нужно. Не открывайте только README — это инструкция, а не сам сайт.

## Что показать преподавателю
- `index.html` — исходный код интерфейса и логики. В этом MVP HTML, CSS и JavaScript собраны в одном файле специально для простого локального запуска.
- `README.md` — назначение, функции, запуск и ограничения.
- `MVP_VALIDATION.md` — критерии MVP и план проверки.
- `docs/PROJECT_STRUCTURE.md` — устройство проекта.
- `docs/DEFENSE_GUIDE_RU.md` — короткая шпаргалка для защиты.

## Как показать GitHub и коммиты
1. Создайте репозиторий `depsentry-mvp` на своём GitHub.
2. Загрузите **все файлы и папку `docs`**, сохраняя структуру архива.
3. GitHub зафиксирует загрузку отдельным коммитом. Для дальнейших изменений делайте небольшие понятные коммиты, например `Add Russian local-run guide` или `Improve dependency parsing` — только после соответствующих реальных изменений.
4. Не создавайте задним числом выдуманную историю. Если преподаватель спросит, объясните честно, что это первая опубликованная версия MVP, а дальнейшая разработка будет отражаться последующими коммитами.

## Важно
Это учебный MVP, а не полноценный коммерческий сервис: здесь нет настоящей авторизации, backend-сервера или облачной синхронизации. История хранится локально в браузере. Отсутствие найденных уязвимостей не доказывает, что пакет полностью безопасен.

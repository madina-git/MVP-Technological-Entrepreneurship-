# DepSentry — Final Exam MVP (обновлённая версия)

## Запуск
1. Скачайте и распакуйте ZIP.
2. Откройте `index.html` в Chrome или Edge. Для стабильной работы API рекомендуется запускать через локальный веб-сервер: из папки проекта в терминале `python -m http.server 8000`, затем откройте `http://localhost:8000`.
3. Интернет обязателен для реального запроса к OSV.dev. Вся история и отзывы сохраняются только в текущем браузере.

## Как показать на защите
1. **New scan** → **Load example** → **Check dependencies**. Приложение выполняет реальные запросы к OSV.dev, а не использует выдуманные результаты.
2. Покажите уровни риска, рекомендации по обновлениям и ссылки на оригинальные advisory.
3. Скачайте **Export JSON** и **Export CSV**, затем **Save PDF** (диалог печати браузера: Save as PDF).
4. Откройте **Reports**, откройте сохранённый результат. Покажите **Backup reports**.
5. Откройте **My account**, измените имя и название рабочего пространства; настройки сохраняются локально.

## 5 пользователей (собрать реальные доказательства)
Попросите не менее пяти отдельных участников выполнить сценарий: открыть сайт, загрузить пример, запустить проверку, найти первую рекомендацию, экспортировать отчет. После каждого теста заполните форму **Quick feedback**, введя уникальный анонимный Participant ID (Tester 01 ... Tester 05). Затем откройте **Reports** → **Export feedback CSV**. Скриншоты, задачи и наблюдения об ошибках следует добавить в evidence appendix. Данные пяти настоящих участников пока **не собраны** автоматически и не должны быть выдуманы.

## Важные ограничения
- Это браузерное MVP без регистрации и онлайн-аккаунтов. «Explore Pro» — информационная кнопка о будущей версии, а не действующая оплата.
- Зависимости отправляются в публичный OSV.dev API по одной для проверки; исходный код никуда не передаётся.
- Точный номер версии обязателен. Диапазоны версий в package.json нужно заменить на фиксированные или использовать package-lock.json.
- Сканирование до 150 зависимостей, файл до 1 МБ. Изменения в составе пакетов и версии уязвимостей могут меняться со временем.
- Результаты OSV.dev и рекомендации не гарантируют безопасность или совместимость обновления: их необходимо проверить на вашем проекте.
- Данные хранятся в localStorage. Для переноса между браузерами предусмотрен **Backup reports**, но импорт резервной копии пока не реализован.
- Проверка UI выполнена с тестовым (подменённым) ответом API; для защиты запустите один реальный скан с доступом в интернет.

## Что улучшено по сравнению с исходным ZIP
- Освежён дизайн; улучшена мобильная вёрстка и клавиатурный фокус.
- Drop zone для файлов, валидация типа/размера файла, очистка ввода.
- Экспорт находок в CSV; отдельный экспорт пользовательского feedback CSV.
- Удаление отдельного сохранённого отчёта и экспорт полной резервной копии JSON.
- Рабочие настройки локального профиля, вместо фальшивого Melissa King.
- Для формы обратной связи добавлен анонимный Participant ID, чтобы фиксировать тестирование разных участников.
- Добавлена проверка некорректного JSON без попытки трактовать его как список зависимостей.
- Добавлены CSS-правила для печати отчёта в PDF.
